A.S DANCE STUDIO — wersja podglądowa skupiona na cheerleadingu.

Publikacja w GitHub Pages:
1. Utwórz publiczne repozytorium na GitHub, np. as-dance-studio.
2. Prześlij index.html i folder assets.
3. Wejdź w Settings > Pages.
4. W Build and deployment wybierz Deploy from a branch, branch main i folder /(root), następnie Save.
5. Adres strony pojawi się w Settings > Pages.

Przed wysłaniem klientce potwierdź grafik i dane kontaktowe. Strona będzie publiczna.
