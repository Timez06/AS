A.S DANCE STUDIO — wersja podglądowa skupiona na cheerleadingu.

Publikacja w GitHub Pages:
1. W repozytorium https://github.com/Timez06/AS otwórz Settings > Pages.
2. Source: Deploy from a branch.
3. Branch: main, folder: /(root), kliknij Save.
4. Aby zaktualizować stronę, w repozytorium wybierz Add file > Upload files i prześlij nowy index.html, zatwierdzając zmiany (Commit changes).
